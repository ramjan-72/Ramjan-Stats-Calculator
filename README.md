# Ramjan Stats Calculator

A C-based calculator that supports **basic arithmetic operations** and **advanced statistical functions** such as mean, median, mode, variance, skewness, and kurtosis.

## 🚀 Features
- Basic operations: `+`, `-`, `*`, `/`
- Mean, Median, Mode
- Assumed Mean
- Harmonic Mean, Geometric Mean
- Variance, Skewness, Kurtosis

## 📦 How to Run
### Using GCC
```bash
gcc main.c -o calculator
./calculator
```

### Using Makefile
```bash
make run
```
